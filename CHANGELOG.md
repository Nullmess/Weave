# Changelog

## [1.0.3]

- Security API v4 and SDK ABI 89.3.
- Optimized SHA-256, HMAC, HKDF and PBKDF2.
- Cooperative cryptographic jobs with progress and cancellation.
- Hardware AES-GCM support and secure resource management.
- Cryptographic performance, RAM and stack benchmarks.
- uFBT-compatible SDK packaging and dedicated build command.
- Automated security, compatibility and firmware validation.
- Android firmware updates over USB/Bluetooth, including optional pre-releases.
- Native Android APK update installation and complete Developer API reference.

## [1.0.2]

- Generic USB HID and CCID APIs.
- Extended cryptography and encrypted secret storage.
- Application permissions and IPv6 support.
- Firmware memory optimizations.

## [1.0.1]

- Networking API v3: HTTPS headers and file uploads.
- Request queue, transport notifications and socket events.
- Updated Android and desktop companions.
- Scoped socket sessions and safe FAP teardown.
- Reliable release checks and Android-assisted firmware updates.

## [1.0.0]

- Custom Flipper Zero firmware.
- Native FAP networking over USB/Bluetooth.
- Native file and app management.
- Android and desktop companions.
